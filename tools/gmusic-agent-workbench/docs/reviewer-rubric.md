# Reviewer Rubric

| Dimension | Pass when |
|-----------|-----------|
| Scope | Diff only touches allowlisted paths |
| Evidence | Trace + audit + verify commands are present |
| Correctness | Acceptance tests exit 0 on the disposable workspace |
| Safety | Rejected out-of-scope or unapproved writes are recorded |
| Ownership | Handoff names residual risk and next human decision |
